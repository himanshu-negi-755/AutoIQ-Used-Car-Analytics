# AutoIQ: Used Car Market Analytics & Price Prediction

AutoIQ is a machine learning-powered dashboard developed using Python, Streamlit, Scikit-learn, Pandas, and Plotly.

## Features

- Used-car market analytics
- Interactive dashboard
- Vehicle price prediction
- Data visualisation
- Machine learning models

## Technologies

- Python
- Streamlit
- Pandas
- Scikit-learn
- Plotly
- PyTest

## Dataset

CarDekho Used Car Dataset (`Car_details_v3.csv`)

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Run Tests

```bash
pytest
```
